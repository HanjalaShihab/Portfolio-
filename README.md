# Hanjala Portfolio

A modern, animated personal portfolio built with React and Vite. It features a custom cursor, scroll-triggered section reveals, and a project showcase with modal details.


## Built With

- React 19
- Vite 7


## Getting Started

### Prerequisites

- Node.js 18+ (recommended)
- npm

### Install

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 🎨 Light / Night Mode

The portfolio ships with both **Light** and **Night** (dark) themes.

- First visit follows your OS preference (`prefers-color-scheme`).
- Toggle anytime via the **sun/moon button** in the navbar.
- Your choice is persisted to `localStorage` (`portfolio-theme`) and used on subsequent visits.
- You can also toggle from the command palette (⌘K → **Toggle Light / Night Mode**).

## 🥚 Secret Commands

The command palette (press **⌘K** or click the ⌘K button in the navbar) contains a hidden layer of Easter eggs. These commands are **only discoverable by typing them exactly** — they never appear in the search results or autocomplete.

Open the palette and type one of these exact commands:

| Command             | What it does                                                                                                                                          |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `space`             | 🌌 Transforms the portfolio into a galaxy — projects become planets, skills become stars, and you can fly between them                                |
| `world`             | 🗺️ Explore **Developer World** — a fictional ocean map where every project is its own island                                                         |
| `timeline`          | 🕰️ Interactive career timeline with expandable milestones, technologies, challenges, and lessons learned                                             |
| `portfolioos`       | 🖥️ Boots **Portfolio OS** — a hidden desktop operating system with draggable windows, apps, and a built-in terminal                                  |
| `office`            | 🏢 Enter a pixel-art developer workspace — interact with the laptop, monitor, coffee mug, bookshelf, whiteboard, plant, desk drawer, window, and door |
| `terminal`          | Opens an embedded Linux terminal (`hanjala@portfolio:~$`) — type `help` to see available commands                                                     |
| `matrix`            | Plays the Matrix digital-rain effect for ~10 seconds before automatically restoring the portfolio                                                     |
| `cat`               | A pixel cat strolls across the bottom of the screen with random speech bubbles                                                                        |
| `quote`             | Displays a random programming quote                                                                                                                   |
| `fortune`           | Reveals a random developer fortune                                                                                                                    |
| `joke`              | Shows a random programming joke                                                                                                                       |
| `coffee`            | Serves a coffee-themed developer joke                                                                                                                 |
| `hello`             | Displays a friendly greeting                                                                                                                          |
| `42`                | The answer to life, the universe, and everything                                                                                                      |
| `make me rich`      | Attempts to... but probably won't 😄                                                                                                                  |
| `achievements`      | Opens your achievements panel (progress is stored locally)                                                                                            |
| `ask`               | Launches a local AI assistant that answers questions about the portfolio                                                                              |
| `sudo hire hanjala` | Runs a playful hiring simulation complete with a subtle confetti celebration                                                                          |
| `rm -rf /`          | Permission denied 😉                                                                                                                                  |
| `konami`            | Activates Retro Mode (CRT overlay, pixel font, retro sound). Also works with the classic Konami code: ↑ ↑ ↓ ↓ ← → ← → B A                             |
| `developer`         | Unlocks a hidden thank-you message after **every achievement** has been earned                                                                        |

### Terminal commands

Inside the `terminal` secret, these commands are available:

```
help · about · skills · projects · resume · contact · github · linkedin
pwd · ls · whoami · history · neofetch · cat about.md · cat resume.txt
clear · exit
```

### Portfolio OS apps

Inside `portfolioos`, the desktop includes:

```
📁 Projects · 💻 Terminal · 📄 Resume · 🏆 Achievements
📓 Developer Journal · 🌐 Browser · ⚙️ Settings · 👤 About
```

Settings (wallpaper + accent color) apply **only inside Portfolio OS** — they never affect the main portfolio theme. The OS terminal reuses the hidden `terminal` experience.

### Office objects

Inside `office`, clickable objects:

```
💻 Laptop → GitHub          🖥️ Monitor → Current projects
☕ Coffee → Dev joke         📚 Bookshelf → Skills & technologies
📋 Whiteboard → Goals       🪟 Window → Download resume
🪴 Plant → Motivational quote  🗃️ Drawer → Secret achievement
🚪 Door → Contact section
```

> Tip: the achievements auto-unlock as you explore — open the palette, find your first secret, try `terminal`, `matrix`, `cat`, `office`, `portfolioos`, `timeline`, `world`, `space`, download the resume, and visit the GitHub link.
