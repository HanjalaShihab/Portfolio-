# Hanjala Portfolio

A modern, animated personal portfolio built with React and Vite. It features a custom cursor, scroll-triggered section reveals, and a project showcase with modal details.


## Built With

- React 19
- Vite 7


## Getting Started

### Prerequisites

- Node.js 18+ (recommended)
- npm

### Install

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 🎨 Light / Night Mode

The portfolio ships with both **Light** and **Night** (dark) themes.

- First visit follows your OS preference (`prefers-color-scheme`).
- Toggle anytime via the **sun/moon button** in the navbar.
- Your choice is persisted to `localStorage` (`portfolio-theme`) and used on subsequent visits.
- You can also toggle from the command palette (⌘K → **Toggle Light / Night Mode**).

### Terminal commands

Inside the `terminal` secret, these commands are available:

```
help · about · skills · projects · resume · contact · github · linkedin
pwd · ls · whoami · history · neofetch · cat about.md · cat resume.txt
clear · exit
```

### Portfolio OS apps

Inside `portfolioos`, the desktop includes:

```
📁 Projects · 💻 Terminal · 📄 Resume · 🏆 Achievements
📓 Developer Journal · 🌐 Browser · ⚙️ Settings · 👤 About
```

Settings (wallpaper + accent color) apply **only inside Portfolio OS** — they never affect the main portfolio theme. The OS terminal reuses the hidden `terminal` experience.

### Office objects

Inside `office`, clickable objects:

```
💻 Laptop → GitHub          🖥️ Monitor → Current projects
☕ Coffee → Dev joke         📚 Bookshelf → Skills & technologies
📋 Whiteboard → Goals       🪟 Window → Download resume
🪴 Plant → Motivational quote  🗃️ Drawer → Secret achievement
🚪 Door → Contact section
```

> Tip: the achievements auto-unlock as you explore — open the palette, find your first secret, try `terminal`, `matrix`, `cat`, `office`, `portfolioos`, `timeline`, `world`, `space`, download the resume, and visit the GitHub link.
