# Hanjala Portfolio

A modern, animated personal portfolio built with React and Vite. It features a custom cursor, scroll-triggered section reveals, and a project showcase with modal details.


## Built With

- React 19
- Vite 7


## Getting Started

### Prerequisites

- Node.js 18+ (recommended)
- npm

### Install

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 🎨 Light / Night Mode

The portfolio ships with both **Light** and **Night** (dark) themes.

- First visit follows your OS preference (`prefers-color-scheme`).
- Toggle anytime via the **sun/moon button** in the navbar.
- Your choice is persisted to `localStorage` (`portfolio-theme`) and used on subsequent visits.
- You can also toggle from the command palette (⌘K → **Toggle Light / Night Mode**).

## 🥚 Secret Commands

The command palette (press **⌘K** or click the ⌘K button in the navbar) contains a hidden layer of Easter eggs. These commands are **only discoverable by typing them exactly** — they never appear in the search results or autocomplete.

Open the palette and type one of these exact commands:

| Command | What it does |
| --- | --- |
| `terminal` | Opens an embedded Linux terminal (`hanjala@portfolio:~$`) — try `help` inside for the full command list |
| `matrix` | Plays the Matrix digital-rain effect for ~10 seconds, then auto-restores |
| `cat` | A pixel cat walks across the bottom of the screen with speech bubbles |
| `quote` | Random programming quote |
| `fortune` | Random developer fortune |
| `joke` | Random developer joke |
| `coffee` | Coffee-related dev joke |
| `hello` | Friendly greeting |
| `42` | The answer to life, the universe, and everything |
| `make me rich` | Good luck with that 😄 |
| `achievements` | Opens the achievements panel (progress is stored in `localStorage`) |
| `ask` | Mini local-only AI assistant that answers questions about the portfolio |
| `sudo hire hanjala` | Runs a fake hiring sequence with a subtle confetti burst |
| `rm -rf /` | Permission denied 😉 |
| `konami` | Activates Retro Mode (CRT overlay + pixel font + retro sound) — also works via the actual Konami code (↑ ↑ ↓ ↓ ← → ← → B A) |
| `developer` | Only works when **all** achievements are unlocked — thank-you message with Contact + LinkedIn buttons |

### Terminal commands

Inside the `terminal` secret, these commands are available:

```
help · about · skills · projects · resume · contact · github · linkedin
pwd · ls · whoami · history · neofetch · cat about.md · cat resume.txt
clear · exit
```

> Tip: the achievements auto-unlock as you explore — open the palette, find your first secret, try `terminal`, `matrix`, `cat`, download the resume, and visit the GitHub link.
